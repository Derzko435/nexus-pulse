Одна консоль, чтоб править всеми: моддеры реализовали на PS5 поддержку игр с Windows и Xbox

12 октября 2026 · Источник: 3DNews

Пока Sony готовится ограничить способы запуска игр для владельцев PS5, создатели неофициального ПО для японской консоли нынешнего поколения работают в противоположном направлении.

Портал Videocardz обратил внимание на два проекта для модифицированной (взломанной) версии PS5, которые предлагают официально не поддерживаемые консолью Sony способы запуска игр.

Разработчик Рафаэль Абуд Феррейра (Rafael Abud Ferreira) представил инструмент PSBox Cloud Gaming (на днях обновился до версии 0.9.5), который добавляет на PS5 нативное приложение Xbox Cloud Gaming для облачного гейминга.
