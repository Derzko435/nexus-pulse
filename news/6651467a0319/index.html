Доисторический кошмар с ужасным вкусом стиля: TeamKill Media анонсировала DLC Primal Charm Collection для экшена Code Violet

9 ноября 2026 · Источник: GoHa.ru

Студия TeamKill Media анонсировала первое косметическое дополнение под названием Primal Charm Collection для своего экшена Code Violet . Релиз аддона состоится 16 ноября 2026 года эксклюзивно для консоли PlayStation 5, а стоимость набора в цифровом магазине составит 6 долларов.

В состав DLC войдут три уникальных костюма для персонажей и три стилизованных раскраски для оружия, объединённых общей доисторической тематикой. Разработчики отмечают, что набор призван разнообразить визуальный стиль прохождения, позволяя игрокам сражаться с угрозами в суровых локациях с большим эстетическим комфортом.

Ранее этот убогий экшен получил патч с контентом и правками.
