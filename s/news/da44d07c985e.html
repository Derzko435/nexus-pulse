Nintendo нанесла удар по рынку прошивок мод-чипов для Switch — Picofly, SX Core, HWFLY и другие жертвы борьбы с пиратством

Крестовый поход Nintendo против пиратства продолжается. В этот раз японский платформодержатель нанёс удар по сегменту аппаратных модификаций для популярной гибридной игровой консоли Nintendo Switch.
